# Samoyed App Icon

Import the three 1024 × 1024 layers into Apple Icon Composer in this order:

1. `00_Background.svg` — opaque background group.
2. `01_Samoyed_Body.png` — transparent Samoyed body group.
3. `02_Facial_Details.svg` — transparent facial-details group.

Recommended treatment:

- Keep the background full bleed and opaque.
- Use Combined mode for the Samoyed body so its fur reads as one coherent glass form.
- Start with subtle refraction and translucency on the body; allow a clear outer specular edge.
- Keep the facial-details group high contrast with little or no translucency so the expression survives small sizes and tinted appearances.
- Do not add baked corner masks, bevels, drop shadows, glows, or specular highlights to the source artwork. Let Icon Composer render those effects.
- Preview Default, Dark, Mono, Clear, and Tinted appearances at small notification and Settings sizes before delivery.
